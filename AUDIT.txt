SCOPE

CHANGES
- Failed settings initialization produces a visible startup error. Saved-view
  operations safely ignore an unready settings object (#7).
- Settings colours are validated at CSS use sites, preserving valid alpha and
  falling back to the existing palette. Invalid values are not saved back (#8).
- Installer diagnostics distinguish an absent Cinnamon executable, an unknown
  version, missing calendar libraries and an unusable probe runtime (#9).
- Successful installs and Spices builds retain only their latest recovery copy;
  failed replacements preserve recovery material (#10).
- Enabled-list validation precedes replacement; enabling failure rolls back
  files. Unchanged lists are not rewritten and detected concurrent changes
  trigger a bounded retry. This is not a compare-and-swap or an atomic
  file/settings transaction. Reload failures retain the new files and backup
  and report failure (#11).
- Screenshots must restore their capture token before publishing. Expiry,
  missing state and restoration failure cannot report a successful image (#12).
- tools/click.py is executable as its usage instructions require (#13).
- A common runner reports suite runs as PASS, FAIL or SKIP, with exit codes
  0, 1 and 77. Optional GUI/private-EDS/live-EDS suites are explicit opt-ins.
  An empty live profile reports skip, not successful verification (#4).
- Offline tests exercise real GLib timer recovery and cancellation, lifecycle
  cleanup, rendering through synthetic actors, navigation, date helpers,
  successful calendar connections, recurrence-family batching, moved exceptions
  and cached results after failures. Date suites use four fixed timezones
  including a midnight rollback and a spring DST transition (#1–3).
- Test state is reset per case. The hidden-event regression was already useful
  (removing its fix makes it fail); coverage now includes actual indexing,
  slicing and parented measurement. Optional St tests measure real labels in
  Cinnamon at four scales. Redundant root-null highlight assertion removed (#5).

KNOWN LIMITS
- Both the historical live-account and private-profile synthetic EDS runs
  completed behavioral checks but exited 139 during native shutdown. Neither
  is a passing integration run. The native finalization crash remains unresolved;
  new offline coverage does not claim to fix it.
- A settings write racing the installer after its final recheck can still be
  lost. Abrupt termination between directory renames can require manual restore
  from a retained recovery copy. Concurrent installers are not serialized.
- Synthetic render tests do not establish all theme, display or window-manager
  behavior. The real St check covers label measurement/hidden counts only.
- Existing recurrence limits remain: RDATE-only/multiple RRULE schedules,
  custom VTIMEZONE and THISANDFUTURE are not fully supported; the 5,000-step
  expansion cap can omit old or high-frequency series.
- No full visual regression was performed.
